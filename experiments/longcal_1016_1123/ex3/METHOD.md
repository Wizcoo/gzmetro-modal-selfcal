# ex3 有界递推偏置估计

每个测点的 X、Y 各维护一个标量随机游走滤波器。当前 V53 输出减去最近有效白天锚得到 d。公共引擎从此前最多 30 个日历日的同一夜间小时取均值 h、标准差 s、有效夜数 n。下列常数在验证和测试前固定。偏置的单位为 mm，方差的单位为 mm²。

```text
phase = clip(h, -1, 1)
confidence = n / (n + 3) / (1 + s / 0.5)
z = confidence * (0.35 * phase + 0.08 * clip(d - phase, -0.75, 0.75))
P_pred = P + 0.0025
R = 0.09 + min(s, 4)^2
K = P_pred / (P_pred + R)
b = b + K * (z - b)
P = (1 - K) * P_pred
```

初值为 b=0、P=0.09。输出使用此次观测更新后的偏置，由公共引擎限幅、限速后从当前 V53 输出扣减。滤波器以实际进入预测的帧为步长。高度重复的夜间相位特征获得较高权重，历史离散度增大时，观测目标振幅和滤波增益均减小。

白天、锚过期、历史不足两夜和采样间隔超过三分钟时，公共引擎重置滤波器。突变保护触发后冻结前一修正和滤波状态，解冻时由公共引擎限制单帧修正增量。合格白天块也会将状态归零。阶段间仅使用已经获得的历史。未接入额外训练任务或外置权重文件。

若历史、门控、初始状态相同，恒定扰动对观测目标的斜率至多 0.08。单元测试检查该条件下的幅值保真。真实序列的门控触发时间和长期历史可能随注入变化，所以端到端检验采用共享回放的配对注入结果。

每实例仅两个 float，合计 8 B，每个双轴测点合计 16 B。附加模型文件 0 B，固定常数编译在 C++ 可执行文件内。完整进程还需容纳 V53 状态、公共相位历史、白天锚和输入输出缓冲，详见实测资源表。单独恢复该滤波器需要同时保留 b 和 P；完整连续回放还依赖公共引擎的其余状态。

原生单元测试使用以下命令。

```sh
g++ -std=c++17 -O2 -Wall -Wextra -pedantic test_candidate.cpp -o test_candidate.exe
./test_candidate.exe
```
