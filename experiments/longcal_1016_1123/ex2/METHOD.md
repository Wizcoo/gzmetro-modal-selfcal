# ex2 白天持续学习适配器

每个设备的每个测点、每个轴独立维护两个 float32 参数。已通过公共质量筛选的半小时块结束时，用该块末值与中位数之差更新有符号端点偏差 b 和绝对端点偏差 s。后者衡量该测点在白天稳定块内仍可出现的波动。冻结 V53，仅在夜间通过公共锚有效期、事件和连续性门控后扣减残差。

令 e = clip(last − median, −0.30, 0.30) mm。每个合格块对下式做一次步长 0.10 的梯度下降。

    L = ½[(b − e)² + (s − |e|)²] + 0.20/2 [b² + (s − 0.04)²]

冷启动值 b = 0、s = 0.04 mm。每个新合格块对旧参数的保留系数为 0.88。输入有界，更新是先验和新观测的凸组合。门控拒绝的块不会传入更新。白天没有任何纠正量，已完成块的参数在后续预测中生效。

夜间，d 表示相对最近可用白天锚的 V53 偏差，h 和 σ 表示同相位历史偏差的均值和标准差，n 为有效天数。将 d 投影至 0 与 clip(h+b, ±1.50 mm) 之间，所得 p 表示当前观测与历史方向一致的部分。将 d 再截断到 ±3s 得 q。请求扣减的偏差为：

    δ = [n/(n+4)] / [1+σ/0.35] · (0.07p + 0.02q)

少于两日历史或输入无效时返回零。白天端点噪声可迁移到夜间是该适配器的实验假设，历史分散时模型会主动降低修正量。在固定锚、固定历史和固定门控下，δ 对 d 的斜率最大为 0.09，单帧扰动至少保留 91%。跨帧斜坡及实际门控切换的保真以统一回放和注入试验为准。

## 边端模型与恢复

实现仅使用 C++17 标准库和编译期常量。外置权重文件为 0 B，每测点双轴在线参数占 16 B，54 点设备的 ex2 学习参数合计 864 B。公共环形历史、锚、门控、V53 和进程工作集另计。config.json 列出本次编译用的常量。

同一 ABI 下保存和恢复全部 8 B 参数即可继续该测点轴的适配器更新。完整应用恢复还需保存公共前处理历史、时间戳、点名/轴映射与 V53 状态，或从已提交帧重放。原生单测覆盖 150 次定常输入后的正则化最优点、无效输入、历史不足、同状态阶跃保持界及 200 次变化输入的中途快照恢复一致性。

    g++ -std=c++17 -O2 -Wall -Wextra -pedantic test_candidate.cpp -o test_candidate
    ./test_candidate
