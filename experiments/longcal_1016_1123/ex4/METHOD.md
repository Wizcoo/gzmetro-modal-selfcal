# ex4 同权重三夜消融

每个测点、轴和夜间小时只读取此前三个**日历夜**内该时段的有效历史。缺失的日期占用窗口，最多提供三晚记录。原版 V53 的三夜模态仍在运行。与 ex1 相比，变动发生在 V53 输出之后的 MLP 历史输入，包括该小时的历史均值、标准差与可用夜数。MLP 两分支的 37 个 FP32 参数、幅值限幅、可信锚、事件保护、输入变换和其他超参数逐项复用。可用夜数仍除以 30。各组共享训练期已经冻结的 148 字节权重，推理时只需本目录和公共处理器。

已组装目录可独立校验。校验包括 C++ 头文件中 37 个字面量逐个转换为 little-endian FP32 后与二进制模型逐字节比对。将三夜窗口声明恢复为 30 后，候选源码的 SHA-256 应与记录的 ex1 指纹一致。文本文件哈希统一行尾，权重二进制按原始字节计算。

```text
python prepare.py
```

要从一个已拟合的 ex1 目录重新组装，运行以下命令。

```text
python prepare.py --ex1 PATH_TO_FITTED_EX1
```

公共评估器按相同的测点、轴和夜晚计算 ex4 与 V53 的比较。追加的配对分析检验 ex1 和 ex4 测试单元、基线方差、有效数、毛刺数、参考锚数与基线误差是否逐项相同，再计算 30 夜相对 3 夜额外获得的方差降幅。正值代表 30 夜窗口的平均方差更低。该差值同时包含历史覆盖和已训练网络响应随窗口改变的影响；未经独立现场观测确认，其物理位移保真度仍待核查。

```text
python compare_histories.py --ex1-results PATH_TO_EX1_RESULTS --ex4-results PATH_TO_EX4_RESULTS --out paired_history.json
```
