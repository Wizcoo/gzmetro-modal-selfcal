# ex1 双流残差 MLP

原版 V53 完成双轴处理后，对每个有效测点和轴独立估计夜间可重复的偏差。所有测点和轴共享一套冻结权重。每个夜间相位的历史统计、最新白天锚和保护门控由公共流式程序维护。

当前观测分支输入距最近有效白天锚的偏移幅值、沿该偏移方向的单帧速度。历史分支输入同相位历史偏移幅值、历史标准差、可用历史日数。两个分支分别经过 4 个 ReLU 单元，8 个激活由单输出 sigmoid 读出修正比例。当前偏差与历史方向一致且至少有两个有效历史日时，修正量上限为当前偏移幅值、历史偏移幅值、0.8 mm 三者的最小值。其余情况输出零修正。所有输入仅依赖当前及已到达数据。

训练采用公共取样器在 2026-11-07 08:00 之前导出的样本。保守伪标签为有符号上限乘以历史可靠度 `max(0, 1 - spread / (abs(hist) + 0.1))`。目标函数为 Huber 残差加修正幅度平方惩罚与参数 L2 惩罚，具体权重见 `config.json`。历史方向相反的样本由运行逻辑精确透传，这些样本计入拟合汇总并从参数优化中排除。最多抽取 120,000 个合格样本，固定随机种子和 48 个训练轮次。验证及测试阶段固定权重。

原生推理依赖 C++17 标准库，权重共 37 个 float32，二进制模型 `model.f32` 为 148 字节。构建使用从同一组浮点数生成的 `weights.hpp`。八个隐层激活逐个计算，MLP 本身没有逐帧堆分配或逐点学习状态。共用日历史和保护状态的内存与实测进程开销另见评估报告。

在本目录用以下命令重建权重，并检查公开的权重文件和原生实现。训练仅依赖 NumPy，验证需 C++17 编译器。

```text
python train.py --samples PATH_TO_TRAIN_SAMPLES_NPZ --out .
python verify_weights.py --work-root .
```

`fit_report.json` 记录训练样本与模型 SHA-256、参与拟合数，以及样本内伪标签误差。测试报告独立评价夜间稳定性、白天保真和事件注入。现场真实变形的保护程度仍依赖独立位移证据，长期可重复的结构运动可能与历史偏移同号。

实际回放产生 56,735 条训练期有效样本，其中 33,199 条有非零同向历史支持。MLP 对全部训练伪标签的 MAE 为 0.004830 mm，零修正的 MAE 为 0.021351 mm。第二次使用相同配置和训练样本从头拟合，所得模型逐字节一致。800 个固定种子的数值对照输入覆盖方向、截断边界附近和历史不足情况，C++17 原生输出与 NumPy 最大差为 2.22×10⁻¹⁶ mm。
