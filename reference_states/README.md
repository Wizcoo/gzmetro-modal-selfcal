V51 参考包和 V53 另存包不能分别直接配对应源码的默认配置导入。此处保留实际文件，不改写参数、时间或 checksum。现场可能显式覆盖配置，本地包不足以证明线上正在运行哪份 DLL 或参数。

- `left/V51_1110_night_reference/`：V51 目录中的“1110 夜间使用 state”。这些设备属于左线，**不能当作右线 V51 的现场状态包**。
- `left/V53_1110_night_initial/`：V53 原交付目录内的“1110 夜间使用 state”。
- `left/V53_saved_copy/`：V53 目录另存的 `state/state/*.state`，按其实际内嵌时间与配置标识，不声称是现场当前最新快照。

参考状态已经核对复制字节和文件内 checksum；本次没有逐包重做算法 Import/Export 验收。软件导入仍须检查设备、点表和数学参数，不能根据目录名绕过校验。线上已有设备继续使用软件可靠持久化的最新配套状态，避免用历史参考快照覆盖当前进度。
