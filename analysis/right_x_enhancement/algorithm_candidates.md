# 保留 V51 的右线 X 增强算法

本研究的主要结果是：A 对独立留一 YJ 残余有小幅一致收益，但本轮没有一个已测增强能稳定改善六路 YXJ 并通过全部注入筛查。所有候选都是研究代码，Y 由原始 V51 独立实例输出。结论及设备限制见 [ranking.md](ranking.md)。

## 1. 来源与同条件基线

已阅读 PR [#1](https://github.com/Wizcoo/gzmetro-modal-selfcal/pull/1)、[#2](https://github.com/Wizcoo/gzmetro-modal-selfcal/pull/2) 的结论、脚本、审计及数值证据。以 PR2 提交 `799d71d011aa16396913675de716d47eb80dfc1f` 为父版本；逐文件来源核对见 prior_evidence_review.csv。原输入沿用 PR1 的同业务键去重、RoiCalState、点名及毫秒时间戳，六设备269个点，全时序不随机采样、不插值。原 JSONL 不重复上传。

原始 `versions/V51/ModalSelfCal.cpp/.h` 直接编译链接，为每设备建立独立原始实例。另一个命名空间隔离的研究实例只在 X 求解/修正边界插入 hook。`identity` 控制要求全部 X/Y 与独立原实例逐位相同；任一不一致立即终止。每个候选也单独维护原始历史、基线和模态，X 使用自己的 context，内部 Y 与原实例逐位核对。没有修改生产文件。

现场实存 `calX` 另列为 `V51_field_observed`，只作观察；其历史状态/配置未匹配，不能与冷启动候选混作同条件 A/B。原始输入及冷启动输出也都完整列入 ablation_results.csv。

## 2. 原算法和不变部分

- [配置](../../versions/V51/ModalSelfCal.h#L14-L36)：K=3，历史最多三夜，22–23基线，22–02学习，23–07修正及20分钟渐入/出，8 mm初筛和2.5 mm残差门限。
- [NewNight/Accumulate/Pooled](../../versions/V51/ModalSelfCal.cpp#L389-L456)：每夜重新累计基线、按 raw−b 累计 S/N；按点名合并历史统计。
- [ModesFrom](../../versions/V51/ModalSelfCal.cpp#L458-L525)：Cij=Sij/Nij，按有效率、spread和guard选学习点，Jacobi求前三阶；非学习但use合格的YJ通过协方差回归得到载荷。**fit_only不是不修正。**
- [SolveV](../../versions/V51/ModalSelfCal.cpp#L530-L581)：原绝对偏差初筛、最小学习数和两次残差剔除仍保留，原解记v0。本轮E/A在该解成功后精化；不尝试救回原本失败的帧。
- [ComputeCbar](../../versions/V51/ModalSelfCal.cpp#L584-L608)、[Ingest](../../versions/V51/ModalSelfCal.cpp#L738-L879)：先冻结本夜b，选历史模态；无历史则02点后才用本夜已完成统计冷启动。原输出为 `calXi=xi−g(t)[Ai v−cbar_i]`。
- [状态接口](../../versions/V51/ModalSelfCal.cpp#L880-L1033)、[门面](../../versions/V51/ModalSelfCal.cpp#L1115-L1247)：严格时间顺序、点名重映射、配置指纹、校验和、完整历史/基线/模态。现场状态不读写。本实验只把自己的内存快照分叉；D等额外context也复制，未伪装成可部署的状态格式。

学习矩阵A、K、点资格、历史累积、Y逻辑及原始降级规则保持不变。新代码位置：[research_hook.h](scripts/research_hook.h) 的 init/estimate/buildSpatial/spatial/apply；[prepare.py](scripts/prepare.py) 用严格源码SHA及唯一锚点生成 `.work/RX.cpp/.h`；[driver.cpp](scripts/driver.cpp) 负责原始独立实例、X轴hook、逐位控制和注入。生成的完整源码不提交，避免复制已有公司实现。

### 增强后的基线零点

增强求解器可能改变23点参考帧的平均系数。候选在模态可用的当时，用已缓存的22–23真实帧，计算 `δbar=mean(v_enhanced−v0)`；运行输出使用 `v_used=v_enhanced−δbar`，保留原cbar。这与为新求解器重新建立基线修正均值等价，不把常量偏移当收益。A还在居中后施加0.25 mm信赖域。资格不足时直接使用v0及原cbar，不能减增强偏置后再冒充回退。空间增量类似用参考帧均值归零。

## 3. E：鲁棒系数求解

在原SolveV成功后的活动学习集L上，原LS为 `G0=Σ AiᵀAi, v0=G0⁻¹Σ Aiᵀzi`。所有正权重下做五次小矩阵IRLS：`v←(Σ wi AiᵀAi)⁻¹Σ wi Aiᵀzi`。

E_Huber用全局历史残差尺度中位数σg，Huber阈值1.345σg。E_full用点级σi、历史精度权重和杠杆限制：

`wi=max(0.05, HuberWeight(ri/σi) × clip(σg²/σi²,0.25,4) × min(1,(2K/n)/hi))`。

`hi=Ai G_L⁻¹ Aiᵀ` 是历史完整学习集的杠杆。σi取历史原始Gram在既有模态LS投影后的残余能量平方根，至少0.02 mm。不是独立测量噪声真值，也没有把点位实际运动当已知噪声。E_Huber与E_full区分“仅Huber”与“历史尺度/杠杆整体加入”，本轮不再搜索更多组合。

无新增硬剔点；原门限的活动集保留。有效点数 `n_eff=(Σw)²/Σw²` 小于max(5,K+2)或奇异时严格回退v0。runtime_and_failure.csv报告原学习数、有效数、降权数、降级、偏离v0及计算代价。

假设：少数学习点残余是污染，历史残余尺度可以代表不确定性。失效条件：真实局部位移也可能被降权；低历史残余点可能只是历史工况安静，未必更可信；固定历史杠杆不能描述所有当前缺测结构。数据中E_full虽改善173835:YXJ3，却明显恶化同设备YXJ2，证明不能把加权视为无条件优于LS。

每帧代价约O(5pK²)，工作状态主要为点尺度/权重/杠杆和3维基线偏置。研究原型为了诊断保留了完整C/R，工程实现可只保留必要对角量；本轮未做生产性能优化。

## 4. A：三阶模态中的YJ软约束

优化学习点Huber损失、YJ参考损失及原解信赖惩罚，而非在输出后回归一条公共曲线：

`min_v ΣL ρ_2.5mm(zi−Ai v) + λ ΣR ρ_1.345((zj−Aj v)/σj) + 1/2(v−v0)ᵀG0(v−v0)`。

λ把参考信息矩阵的迹限制为原学习矩阵迹的0.25倍。参考权重随当前参考残差Huber降权；最后限制任一use点的新增模态修正幅值≤0.25 mm。参数是开发期固定方案，不是上线推荐值。

参考资格包括：

1. 历史模态解释能量≥0.8，且use合格；至少3个历史合格YJ以提供单异常冗余。
2. 历史基线中心Gram的参考两两归一化绝对相似度中位数≥0.7。它是二阶能量相似性，不冒充中心化Pearson相关。
3. 当前至少2个有效参考；按第一模态载荷符号定向的标准化参考残差做中位数/MAD一致性筛查，超过3倍尺度剔除；仍至少2个。
4. 原学习点有效、原SolveV成功，否则回退；无YJ的298317/333715严格回退。

当前一致性筛查是参考创新的空间一致性，不是新的滚动时间相关估计。它可能漏掉多个参考同型异常，正是注入暴露的限制。单参考故障本轮最大额外关键点响应约0.066 mm；多参考共同异常约0.170 mm，仍不满足本研究0.1 mm附加污染筛查。

**独立留一**：当前目标YJ从参考约束中移除，剩余参考估计v，再预测该目标；原历史载荷Ai保留，故不是未见点泛化。未入选的YJ1当前本就不参与约束，其A输出可直接作独立预测。LOPO只在可用时记值，另给同样行的 `V51_on_A_LOPO_rows` 对照；重建时还原b和实际g，不能把居中残差与原坐标混用。

两夜LOPO低频范围比值的中位数约0.918和0.968，说明参考信息有作用；但YXJ第一夜无稳定收益、376393:YXJ6两夜变差。固定Ai把改善YJ的系数改动传播给YXJ时，仍可能不适合其当前响应。此证据支持继续研究参考约束，也要求额外的目标影响保护和新的隔夜检验，不能直接启用。

E+A因独立方案未通过跨夜/注入条件而未开展，见 joint_decision.json。运行代价约O(5(p+r)K²)，附加当前LOPO诊断会重复求解；状态是参考资格/尺度、3维偏置及诊断量。

## 5. B：原模态之外的空间增量

centerX/centerY在两夜各自基线窗有稳定记录，可作为**原生配置位置代理**作数值筛查；缺少写入实现和相机标定，未证明它们是世界坐标，也未将比例/姿态解释成真实几何。coordinate_qualification.csv和spatial_identifiability.csv逐设备列出资格。

比较 `H=[1]`、`H=[1,u]`、`H=[1,u,v]`。u/v以该夜基线已知配置标准化；一维轴按参考点配置跨度选择，不看测试位移。先投影：

`Q=H−A (A_LᵀA_L)⁻¹A_LᵀH_L`。

对残余列再正交化，投影后能量不足原列5%的方向移除；最终维数d只计独立残余方向。零维严格回退。当前学习集须完整有效，以保持该正交关系。参考数至少d+2，参考设计矩阵条件上界≤30；历史残余协方差R中逐一留参考预测，其期望残余能量相对不补增量至少降低20%，才允许解 `γ=(Q_RᵀQ_R)⁻¹Q_Rᵀr_R`。输出只加Qγ，不再重复拟合已有A分量。空间估计幅值限0.25 mm再按基线均值归零；不同输入场景之间的增量差可达0.5 mm，不能把单场景幅值上限当异常隔离保证。

初始逐列全拒绝的实现使所有B停用；在任何有效B评价前，修正为移除冗余列后继续检查独立梯度，未修改阈值、未按测试收益选参。此设计澄清记录在冻结方案中。

结果：纯平移已被A子空间覆盖；346578的位置一维/二维历史留一能量收益约−3.7%/−75.3%，停用。173835与376393的一维数值代理通过历史筛查，但跨夜YXJ不稳定，且单参考异常传播可到0.167 mm、多参考可到0.500 mm。二维在其他设备缺乏独立参考冗余；414923没有足够独立残余方向。**没有可进入工程实现的空间增强。**

失效包括：坐标语义不明、投影后秩低、参考几何集中、参考不足、当前缺测破坏正交、参考异常及训练/测试残余关系变化。即使以后数值收益更好，也仍须核实配置坐标的实际业务含义。每帧O(rd²+pd)，状态Q和小矩阵/偏置；本轮只作数值代理机制研究。

## 6. D：对v的因果时序估计

只处理三维系数，不平滑原始各点。D_EMA为 `vhat_t=0.5v0_t+0.5vhat_(t−1)`。D_Kalman在每阶系数上用随机游走、Q/R=1；R来自已完成历史的学习残余经G_L⁻¹传播，设置数值下限。创新超过3倍预测标准差时直接重置到当前v0，**不冻结大变化**。跨夜、>90秒缺口和失效恢复重启状态。

已知模态形状阶跃中，可辨识响应的EMA 95%响应最多4帧（从第一帧计为索引0），Kalman大创新重置为0帧，满足本研究约5帧约束。333715没有YJ/YXJ，无法按“关键点最大值”归一化该模态形状，相关时延条目标为不可辨识，绝不记为0帧通过。时间结果是同输入相对原模型系数响应，不是物理位移时延；慢斜坡、缺失恢复和真实时序滞后代理另列。

EMA虽然时延有限，仍可明显扩大346578残余：第一夜YXJ6低频范围约0.250→0.448 mm，第二夜0.441→0.557 mm。原因是当前补偿量跟不上快速公共变化。Kalman更接近原解，在298317:YXJ4两夜低频小幅改善约1.8%/2.8%，但其他通道有退化，没有全线稳定收益。复杂度O(K)，额外滤波状态约2K个数和时间戳；若工程化须把额外状态纳入明确的版本/恢复协议，本轮仅复制研究context。

## 7. C：历史夜适应的边界与后续方案

原C按各夜S/N合并。近期加权应为 `Cij=Σ αn S(n)ij / Σ αn N(n)ij`，有效率判定的总帧数也须同权加权，不能只乘协方差或不一致地改变资格。参考选择可在23点之前仅使用该夜22–23特征，对已经存在的历史夜选权；不得用当天23点之后结果选模态。

本窗口第一夜02点才完成第一份统计，第二夜23点只有一份过去历史。单夜共同权重在S/N中抵消；第二份统计完成时，本夜A已经冻结。11/07后续新夜不在本轮数据中。因此没有可识别的“最近三夜/近期加权/参考选历史”同条件效益比较，未伪造C输出。historical_adaptation_limits.csv逐设备记录此限制。

C在本轮仅有数学设计，不参与性能排名。未来需要多份已完成历史、读取新验证夜结果前冻结方案，检验加权是否真能解决载荷关系变化。风险包括近期异常污染历史、参考特征不代表后半夜、状态指纹及有效率权重不一致；运行主要仍是每夜p×p统计合并/特征分解，不应凭两夜数据提出上线参数。
