# 右线 X 修正不足：第一轮数据诊断

结论：现有证据支持“整体共模已明显减弱，但少数点不修正、部分点修正后的变化反而增大；下游滤波/减初值又改变了波形与时序”。不能据此证明串联几何放大，更不能把全部变化认定为硬件噪声或给出最优参数。优先查点级名单/有效性/状态资格和历史载荷；暂不全局调整 K、8 mm 门限或扩大平滑。

范围为北京时间 2026-11-05 00:00 至 2026-11-07 15:00；末条可用下游记录 11/07 14:59:00.825。使用现有右线 JSONL，未重读原 SQLite。生产 V51/V53、配置、状态和现场均未改动。

## 1. 最强证据：先确定正在比较哪个阶段

- 去重后下游共 **754,755 条、201 个名称、3,755 个时间戳**。跨卷移除 12,060 条完全相同观测，没有冲突业务键。
- 全部记录都满足 `x0≈filteredX0−initX`、`y0≈filteredY0−initY`，最大差 0.0001 mm（落库舍入量级）。**本批 x0 不是可以直接当作串联原始输出的字段。**
- postFilteredX0/Y0 全为 0，12 个 YJ/YXJ 名称的 x0/y0 等字段也恒零；不能把这些当作真实零位移或优良精度。
- 大部分 MarkerData.deviceId 为空；按同名同时间保留全部候选父观测：503,170 条有一个候选、247,830 条有两个、3,755 条有三个，无同名时间完全无法匹配记录。该成员关系不等于解算拓扑。
- 五个非空 deviceId 将 YXJ2–6 与对应设备明确连接，双方 x/y 完全一致，但 YXJ4–6 的 x0/y0 所处阶段不同。
- 依据：[pipeline_trace.md](pipeline_trace.md)、[字段恒等式](field_identity_checks.csv)、[映射](explicit_device_marker_mapping.csv)、[数据组织审计](data_audit.json)。

## 2. 最大白天扰动不能直接归责于夜间共模参数

- **RX01：780639346578 / YD2603，11/05 09:45–13:15。** x0 峰谷差 **34.9857 mm**，原始 X 与 calX 的峰谷差均为 **22.4429 mm**，窗口内没有实存补偿；名义上处于白天。该窗口还有初值变化，不能等同于纯硬件噪声。
- **RX02：780639173835 / YD1604，11/05 12:49:41.412。** initX 跳变 **+10.3692 mm**；同一步 filteredX0 仅 **+0.0062 mm**，x0 则 **−10.3629 mm**，恰好由减初值解释。这一步不能算作 ModalSelfCal 输出的跳变。
- 11/05 11:30:19.757–11:53:47.331 下游 MarkerData/SubDeviceDisData 有 **23.46 分钟缺口**；上游六表最大缺口约 3.27 分钟。缺口后坐标、过滤值和随后初值改变的先后关系见连续 CSV；没有重启/运维日志，不能直接命名为某次维修或参考图重置。
- 原始/下游波形恢复存在明显拖尾，但当前缺少滤波实现，不把极值时间差当作已识别的固定滤波延迟。真实位移、操作调整和识别异常仍需现场证据。

- 同期 raw Y/calY PV 为 **3.1364/3.5062 mm**，局部 Y 也有残余，不能声称所有 Y 点都完美。x0 的5分钟中位数相对局部基线最大偏移 **7.0554 mm**，超过1 mm的连续段约 **37 分钟**，不是仅一个瞬时尖峰。

- **可确认**：在相同有效样本上，该点记录的补偿扩大了 X 波动；不是整个设备 gate 关闭。
- **待验证**：历史模态/回归载荷失配、点的局部光学/硬件响应变化、基准变化后历史统计不再适用，或软件 calX 接线/点序问题。没有真实位移标签，不能把 calX 波动增大直接命名为准确度下降。

### 780639346578 / YD3104：两夜持续没有实存补偿

- 两个整夜 X 的 raw/cal PV 分别均为 **5.1441 mm**、**5.9689 mm**；X/Y 修正量均恒为零。同设备两夜均有 **99/100** 个 Marker 出现非零修正。
- **RX06：11/06 01:12–02:42**，目标有效率100%，raw/cal X PV 均 **4.0172 mm**，与其他 YD 点共模相关约 **0.869**，下游 x0 PV **5.2225 mm**，持续偏移超过1 mm约27分钟。
- 现有 11/05、11/06 两个 22:00–02:00 学习窗，该点均有60个有效基线观测、学习窗观测有效率100%。因此“本夜样本不足”不是这两窗的解释。历史三夜 use/learn/载荷、Init 点表与调用方 NaN 屏蔽仍未知。
- **优先核实**：运行名单是否包含该点、点名/向量顺序与数据库写入对应、历史状态 use 资格、逐轴 A 载荷，以及软件是否把该点输入屏蔽或直接回填 raw。不能仅因该点未修正就断言需要增加 K 或修改 min_valid_ratio。

## 5. 为什么仍有下游 x0 波动：能说到哪一步

1. 部分关键点的 calX 本身仍有大波动（YD3104未补偿）或已被实存补偿扩大（YD2603）。无需假设几何放大，也足以解释为何不能期待下游所有点都平稳。
2. x0 还叠加了 filtered 的时序作用和 init 的改变。RX02 用差分恒等式直接证明初值贡献；不能把所有 x0 尖峰归给共模。
3. 同名精确时间关联、环境和姿态变化支持时序线索；极值滞后可见，但相关斜率/时间差不等于已知串联 Jacobian、固定滤波模型或因果传递增益。
4. 缺少求解器、标定、控制/传递点拓扑、初值状态、当前调用方和云发布字段。因此**“串联放大了多少”“云最终改善多少”本轮不能定量确认**。未伪造任何原始/修正同条件串联重算。

## 6. 下一轮最小修改的优先级与可量化验收

对应本轮要求的五类场景：

| 场景 | 本轮定位 | 证据边界 |
| --- | --- | --- |
| 模型未有效工作 | YD3104 点级没有实存补偿；其余99点有补偿 | 无法进一步区分名单、输入屏蔽、use资格和落库回填，不支持全设备模型停用 |
| 模型有效但仍有残余 | 六设备的整体X共模明显减弱，部分逐点X指标仍大于Y对照 | 没有真值，不能把残余一律认定为噪声或必须继续吸收 |
| 局部响应不一致/模态表达失配 | YD2603与其他点存在共模关联，却被实存补偿扩大波动 | 硬件原因与历史载荷失配是待验证假设 |
| 串联放大上游残余 | 同名时序及显式YXJ设备关系提供排查线索 | 缺少求解器与几何，尚未证明放大，更未定量计算灵敏度 |
| 真实物理位移/未知事件 | 日间大幅变化、观测缺口和局部持续偏移均保留 | 没有独立真值或现场事件记录，不把它们消成零 |

1. **先查输入与状态接线，保持生产不动。** 对346578重点核对YD3104名单/NaN/use/learn/A和raw→cal落库；取得匹配时刻的V51配置及状态指纹。此项优先于修改全局K、spread、min_valid等参数。
2. **再验证X点级学习/载荷假设。** 用现有K=3做控制回放，分别比较YD2603历史统计在11/05观测变化前后的适用性、局部回归载荷与实际X协同变化；不要先把变化当噪声删除。只有控制回放支持，才提出最小的X专用资格/学习改动。
3. **把减初值和过滤波形作为独立验收环节。** RX02 的10.3692 mm初值变化应单独标记；不要靠扩大共模窗或强平滑去掩盖它。
4. **串联A/B是下一步必要证据。** 在取得同一标定、拓扑、初始化和真实调用接口后，两路使用完全同时间戳/有效性和独立求解器状态。比较关键点、下游x0及真实发布值；当前现场x0不得冒充原始输入重新解算结果。
5. 验收至少包含两整夜、日间控制、完整连续性、缺失与失败帧、YD2603 cal/raw PV与步差、YD3104覆盖、16事件x0/filtered/init分解及Y逐点回退。用相同样本和局部基线，输出10/30/60分钟漂移、相邻步差、去趋势残差；不预设最优数值参数、不用物理零位移作为标签。
